About Us

ဟိုင်း။ VeraHrt လေးမှကြိုဆိုပါတယ်။ ဒီ Project လေးကတော့ Diy Hrt ( ဆရာ၀န်ညွှန်ကြားချက်မရှိဘဲ ဟော်မုန်းဆေးသုံးခြင်း ) လုပ်နေတဲ့ transgirls၊ transwomen လေးတို့အတွက် အခြေခံသိထားရမဲ့အချက်တွေ၊ ကျန်းမာရေးမထိခိုက်အောင် ရှောင်ကြဉ်ရမဲ့ အချက်လေးတွေကို မြန်မာလိုမှတ်တမ်းပြုပေးထားတဲ့ Website လေးပါ။

About Me

Hi, ကျွန်မကတော့ Laura/Stella ပါ။ အခု harm reduction website လေးကိုလုပ်ရတဲ့အဓိကရည်ရွယ်ချက်က မြန်မာမှာရှိနေတဲ့ transgirl transwomen လေးတွေ အန္တရာယ်ကင်းကင်းနဲ့ diy hrt ပြုလုပ်နိုင်ဖို့အတွက်ဖြစ်ပါတယ်။ ဆရာ၀န်ရဲ့ညွန်ကြားချက်မပါဘဲ ဆေးသောက်/ဆေးထိုး/ဆေးလိမ်း ကြရတာဖြစ်တဲ့အတွက်ကြောင့် ဒီလို harm reduction လေးတွေ သိထားဖို့အလွန်အရေးကြီးပါတယ်နော်။ ဒီ website ထဲမှာ သိသင့်သလောက်အကုန်ရှင်းပြထားပါတယ်။ တအားကြီးဆေးဖက်ဆိုင်ရာရောက်မသွားချင်တာကြောင့် အတက်နိုင်ဆုံးရိုးရိုးရှင်းရှင်းဘဲရှင်းပြပေးထားပါတယ်ရှင့်။

ဒီ Project လေးကို Support ချင်တယ်ဆိုရင် မုန့်ဖိုးလွဲပေးလို့ရပါတယ်နော်။

မုန့်ဖိုးမပေးဘဲနဲ့လဲ support ပေးနိုင်ပါတယ်နော်။ ဘယ်လို support ရမလဲဆိုတော့ ဒီ website လေးကိုတခြား transgirl transwomen လေးတွေကို မျှ၀ေပေးခြင်းဖြင့် ကူညီပေးနိုင်ပါတယ်ရှင့်
